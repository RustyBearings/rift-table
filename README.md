# Rift Table

A League of Legends macro sandbox — scrub a game minute by minute on the map and read the
position like a chess engine: gold lead, next play, scoreboard, structures, objective
timeline. Drag champions to test a rotation, or right-click one to kill it and read the 4v5.

Live: https://rustybearings.github.io/rift-table/
